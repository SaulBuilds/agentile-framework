## Getting Started

1. Create or rewrite [`../SPIRIT.md`](../SPIRIT.md) using [`../SPIRIT_GUIDE.md`](../SPIRIT_GUIDE.md) if the repo still speaks like the starter.
2. Refactor [`../README.md`](../README.md) so it describes the actual project.
3. Create your first sprint directory: `.agentile/sprints/active/sprint-1-<name>/`
4. Copy `templates/SPRINT.template.md` to `SPRINT.md`, `templates/DAILY.template.md` to `DAILY.md`, `templates/JOURNAL.template.md` to `JOURNAL.md`, and `templates/REPORT.template.md` to `REPORT.md`.
5. Define your work packages and acceptance criteria.
6. Update this file to reference the new sprint.
7. Follow the [SPRINT workflow](../workflows/SPRINT.md).
